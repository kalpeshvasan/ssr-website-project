# Next.js 30-Page UI Kit Starter

Modern Next.js App Router + React 19 + TypeScript starter.

Included:
- 30 website routes
- responsive accessible mobile hamburger menu
- centralized `src/ui-kit/theme`
- reusable components, templates and page compositions
- SEO metadata, sitemap and robots
- Server Components by default
- ESLint + Prettier + Husky
- Zod
- loading/error/not-found boundaries
- no Jest, Vitest, React Testing Library or Playwright
- React Compiler disabled

Run `npm install` then `npm run dev`.

UI Kit routes:
`/ui-kit`, `/ui-kit/templates`, `/ui-kit/pages`
